# MNV Associates — Premium Next.js Homepage

Research-informed homepage concept for the MNV Associates proof-of-work assignment.

## Stack
- Next.js / React
- Tailwind CSS
- Lucide React
- IntersectionObserver scroll-reveal animations

## Included interactions
- Services desktop mega-menu with smooth hover transition
- Menu item underline / after animation
- Mobile Services accordion animation
- Scroll-based section reveal with staggered delays
- Directional reveal animations for content and imagery
- Image zoom and card hover micro-interactions
- Floating hero focus card
- Reduced-motion accessibility support

## Images
The concept uses remote Unsplash images for the visual prototype. For production, replace them with licensed MNV-approved imagery or local assets.

## Run
```bash
npm install
npm run dev
```
